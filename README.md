1. 설명
   - AI 꽃 캐모마일과 대화를 나누며 일상과 고민을 털어놓고
     위로를 받을 수 있는 힐링 게임입니다.
     이 게임을 통해 감정적으로 공감하고 대화하며
     남에게 쉽게 말하지 못하는 이야기까지 나눌 수 있어 정서적인 안식처를 형성할 수 있습니다.
     또한 최근 청년들은 온라인에서 관계를 맺고 소통하는 경우가 많아지고 있는 만큼,
     AI와의 교감을 통해 위로와 지지를 경험하며
     정서적 안정감을 얻을 수 있도록 하는 것을 목표로 합니다.

2. 기능
   - AI 캐모마일과의 대화 ( 말풍선 버튼, 왼쪽상단 돌아가기 버튼으로 원래 UI로 돌아갈 수 있음. )
   - 캐모마일 돌봐주기 ( 하트 버튼, 애니메이션 재생 )
   - 캐모마일 물주기 ( 물방울 버튼, 애니메이션 재생 )
